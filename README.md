# parcheggio-facile
aiuto a trovare la macchina

App per salvare il parcheggio e ritrovarlo con Google Maps.

## Attivazione
Settings → Pages → Deploy from a branch → main → / (root) → Save.

Aprire https://baudinolorenzo73.github.io/parcheggio-facile/ in Chrome e scegliere Aggiungi alla schermata Home.

I dati restano nel browser. Vedere LEGGIMI.txt per funzionamento e limiti.


## Parcheggio Rapido
`rapido.html`: un solo pulsante per salvare il punto in fretta. `parcheggio.html` lo importa automaticamente (stessa cartella = stessa memoria del browser).
